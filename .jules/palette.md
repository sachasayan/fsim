## 2024-05-22 - Missing `<kbd>` elements in Shortcut Help Modal
**Learning:** The Shortcut Help Modal lists keyboard shortcuts using plain text instead of proper `<kbd>` tags. `<kbd>` elements are semantically correct for keyboard input, improving accessibility and visual styling potential for shortcuts. This is a common pattern across many applications that should be standardized.
**Action:** Wrap keyboard shortcuts in the Shortcut Help Modal with `<kbd>` tags and apply simple styling to make them visually distinct and accessible.
