## 2024-06-11 - FieldRow Missing Input Linking
**Learning:** The `FieldRow` component uses a `<label>` element but doesn't link it to the input it wraps using `htmlFor` and `id`, breaking accessibility for screen readers clicking on the label. But wait, `FieldRow` wraps different types of components, so we might need a way to pass an ID down. The prompt states: "In this codebase, the `FieldRow` layout component lacks `htmlFor`/`id` bindings for its child inputs. When placing interactive components (like `<Input>` or `<SelectTrigger>`) inside `<FieldRow>`, you must explicitly pass an `aria-label` to the input to ensure screen reader accessibility."
**Action:** Always add an `aria-label` to interactive inputs/selects inside `FieldRow` components where an explicit connection to a label is missing.
