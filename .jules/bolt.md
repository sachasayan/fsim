## 2024-05-24 - Precalculating Perlin Noise Hash Gradient Operations
**Learning:** In hot procedural generation inner loops (like the `Noise.fractal` algorithm), manually expanding exact math with unrolled expressions and lookups directly indexed into typed arrays provides huge execution overhead reductions compared to nested helper functions, but the strict math outputs MUST match the previous nested operations bit-for-bit to pass strict deterministic CI assertions like `terrain-synthesis.test.mjs`. Simply extracting methods to the module scope and manually inlining `fade` equations provides a significant speedup while guaranteeing exact math parity.
**Action:** When refactoring procedural generation math, always ensure operations maintain exact precision without expanding equations like `(x + 1) * C` into `x * C + C`. Rely on readable micro-optimizations like hoisting functions/arrays to module scope instead of massive inlining if it sacrifices readability.
