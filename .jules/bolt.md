## 2024-05-24 - V8 Context and Function Calling Overhead in Math Hot-Paths
**Learning:** Calling functions (even simple ones like `fade` or `lerp`) via `this.func()` inside extremely hot procedural generation loops (like Perlin noise) creates massive execution overhead and prevents V8 from efficiently JIT compiling the loop. Moreover, accessing heavily used static typed arrays from the object instance (`this.permutation`) rather than a module-scoped constant causes significant slowdowns.
**Action:** For heavy math loops called millions of times per frame/tick, hoist static properties (like `permutation` tables) to module-scoped constants, and inline small helper functions (like `fade` and `lerp`) directly into the loop body to avoid context switching and property lookup overhead. Keep these optimizations contained to proven bottlenecks to preserve overall code readability.
