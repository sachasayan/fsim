## 2024-05-20 - Un-nesting Perlin Noise Math
**Learning:** Extracting Math.floor arrays into constants outside functions, manually expanding `fade` inline instead of using a helper method, and simplifying math expressions using explicit local variables `x0`, `x1`, `y0`, `y1` without arrays to hold intermediate results avoids `this.*` lookup overhead and reduces the benchmark runtime from ~130ms to ~107ms for `Noise.fractal`. Furthermore, manual loop unrolling for specific octaves scales inside `fractal` and precomputing `sx=x*scale` combined with single inline multiplications proved extremely effective. Replacing Math.floor with bitwise truncation breaks the math and determinism, so it is strictly avoided!
**Action:** Always extract inner-loop calculations in high frequency components (like Noise generation), prefer inline calculations over abstractions for raw number crunching, un-nest deeply nested function calls into explicit variables, and keep using module scoped methods/variables rather than properties inside an object.
