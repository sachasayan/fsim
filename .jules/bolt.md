## 2025-02-23 - JavaScript Object Property Lookup Overhead in Hot Math Loops
**Learning:** In highly intensive procedurally generated hot paths like `Noise.fractal`, maintaining state arrays or helper methods (like `this.fade` or `this.permutation`) on an exported object directly impacts execution time due to JavaScript engine property resolution/context lookup. Inlining standard functions didn't yield as much gain as manually expanding variable scopes or caching repetitive math (like the `valueNoise2D` trigonometric expansions).
**Action:** Always hoist constants, mathematical arrays, and helper functions (like `lerp`, `grad`, `fade`) to the file/module scope. Expand small constant math operations manually inside critical `for` loops rather than using generic reusable functional calls for complex noise math.
