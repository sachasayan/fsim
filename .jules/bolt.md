## 2024-10-24 - Pre-calculate and Inline Perlin Noise Math
**Learning:** Math.floor and many internal function calls slow down hot loops in the noise generation. Unrolling the interpolation (fade, lerp, grad) into inline mathematical expressions manually saves significant time (from ~128ms to ~107ms for `Noise.fractal`), resulting in a solid performance win without breaking strict deterministic outputs (as long as bitwise truncation like `| 0` is avoided for potentially negative numbers).
**Action:** When a performance bottleneck is identified in mathematical hot loops like Perlin Noise, inline helper functions directly and pre-calculate array lookups in local variables rather than using property accessors like `this.lerp`. Retain the exported original helper functions for backward compatibility.
