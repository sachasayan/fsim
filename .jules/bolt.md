## 2024-05-12 - Inlining Performance in V8
**Learning:** For extremely hot loops like Perlin noise generation, fully expanding mathematical expressions (like `fade`) into the parent function, converting class methods into static functions and pulling out static arrays into module-scoped `const` references avoids `this.*` context overhead, and achieves ~15-20% performance improvement (from ~125ms median to ~106ms). Re-structuring complex `lerp` blocks into separate explicit variables instead of massive nested calls also helps V8 execution significantly.
**Action:** Extract reusable arrays, completely inline simple math helper functions that are called frequently within inner loops, and un-nest deeply nested function calls into distinct variables when optimizing for peak V8 performance. Ensure exact mathematical equivalents are maintained for deterministic tasks.
