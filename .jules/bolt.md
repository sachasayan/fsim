## 2025-05-05 - V8 Math Object Property Binding Overhead in Hot Loops
**Learning:** In procedural generation hot loops (like Perlin Noise `Noise.fractal` inside terrain generation), excessive `this.*` context resolution and looking up properties on objects rather than module-scoped static arrays introduces measurable overhead that V8 fails to optimize away reliably across millions of iterations.
**Action:** When optimizing tight numerical loops, replace `this.property` object access with module-scoped variable lookups (e.g., extracting the `PERMUTATION` array out of the `Noise` object), and replace `this.method` calls with direct invocations or manual inlining (like manually inlining `fade(t)` math) to assist V8 optimizations. Ensure this still maintains identical numerical determinism for `tests/terrain-synthesis.test.mjs`.
