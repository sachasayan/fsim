## 2024-06-01 - Optimizing Noise.noise execution overhead
**Learning:** V8 struggles to inline mathematical functions perfectly when referenced through `this` context objects or object lookups inside highly-called hot paths like Perlin noise generation. Extracting standard math functions (like `grad`) directly as local module-scoped functions instead of using `this.grad`, explicit inline evaluation over repeated chained object method calls, and removing deep nesting (like `this.lerp(this.lerp(...))`) resulted in a near ~30% speedup.
**Action:** When optimizing tight mathematical inner loops, prioritize extracting helper functions to module scope and expanding math manually rather than relying on `this.*` calls, as avoiding `this` and un-nesting operations significantly improves JS engine execution speed.
