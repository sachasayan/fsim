## 2024-05-24 - V8 Context Lookups in Hot Paths
**Learning:** In highly mathematical procedurally generated inner loops (like Perlin noise fractals evaluated hundreds of thousands of times), V8's function property access (`this.*` context bindings) creates significant overhead. Furthermore, extracting nested helper calls like `lerp()` and `grad()` into completely unrolled raw expressions yields a massive reduction in V8 execution overhead even when replacing pure `Math.floor` calls with bitwise logic failed validation testing previously due to precision strictness on negative floats.
**Action:** Always prefer unrolling simple algebraic helper methods natively inline rather than executing them out-of-context, and strictly pull static shared lookup arrays (like `.permutation`) into module-scoped constants instead of property lookups for deterministic math processing where precision requires 100% test parity.
