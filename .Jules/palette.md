## 2024-04-07 - Flight Simulator Dashboard & Canvas Accessibility
**Learning:** Complex WebGL/Three.js applications often use a `<canvas>` element surrounded by complex HTML dashboards (like flight displays). Screen readers cannot interpret the contents of a `<canvas>`. Wrapping it in `div`s isn't enough; the `<canvas>` itself requires `role="img"` and an `aria-label` to be perceivable as an intentional element rather than an empty space. Additionally, surrounding dashboard widgets benefit from `role="group"` to act as navigable landmarks.
**Action:** When working on WebGL/Three.js user interfaces, always apply `role="img"` and descriptive `aria-label` attributes directly to the `<canvas>` elements, and use `role="group"` with labels for surrounding HTML dashboard components to provide semantic structure.
