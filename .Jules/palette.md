## 2024-04-12 - Disabled Button Tooltips with Radix UI\n**Learning:** When using Radix UI Tooltips around custom buttons, disabled buttons with `pointer-events-none` will not trigger tooltips to show because the pointer events are swallowed. Ensure the underlying native button element explicitly receives an `aria-label` (falling back to the `title` prop if available) so icon-only buttons remain accessible to screen readers even when disabled.\n**Action:** Update the `CommandButton` and other icon-button components to ensure they pass `aria-label` or `title` down to the native `<button>` element.
